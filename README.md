# Invoice Generator

A React app for creating invoices, calculating GST, and exporting invoices as PDF.

## Run locally

```sh
npm install
npm run dev
```

## Deploy to GitHub Pages

The GitHub Actions workflow builds and deploys the app to GitHub Pages whenever changes are pushed to `main`. Enable **Settings → Pages → Build and deployment → Source → GitHub Actions** in the repository to allow the workflow to publish.

After the first successful deployment, the app is available at:

https://geetharamalingam6-art.github.io/invoice-generator/

## Build

```sh
npm run build
```
